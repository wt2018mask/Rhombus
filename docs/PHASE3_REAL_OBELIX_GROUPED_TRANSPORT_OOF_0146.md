# 0146 — Real 478-row OBELiX TRAIN grouped out-of-fold conductivity diagnostic

**This is an actual predictive benchmark calculation using real source data**, not only a source-inventory validation. It trains a deterministic **composition-only ridge regression** and a training-fold-mean baseline and predicts withheld **original TRAIN** source rows. Target: log10(positive original numeric conductivity in S/cm). 0146 reads the **original first-party raw.xlsx** via the existing 0130 → 0133 → 0134 hash-bound original censoring pipeline and cross-joins the TRAIN input composition and DOI records. Strict original upper bounds **NEVER** enter point-target regression or reported point MAE; unrecovered labels and unparseable compositions are excluded, but included in denominator / coverage reports.

To avoid falsely good accuracy from copied compositions and shared source references: construct **connected components** across all source TRAIN records with a *shared DOI OR same parsed reduced composition*. Source rows in a connected component are assigned to **only one of five folds**, assigned deterministically in descending group size to balance held-out counts; every prediction comes from a model fitted exclusively on the other four fold groups. Group leakage must be explicitly checked in the tests and at runtime. This is a conservative source-record graph, **not** proof of independent experimental specimens or successful source-paper de-duplication. An ambiguous group that spans multiple studies stays grouped; no IID claim.

Represent chemistry by 118 normalized elemental-fraction descriptors using **pymatgen Composition** (parsed/validated before model fit). The ridge model uses a training-only feature scaler and a fixed regularization coefficient; five independent fold fits, with no test-set hyperparameter tuning. Publish only a **small aggregate**: source commit/processed/raw hashes, TRAIN/TEST counts, numeric/censored/unresolved/parse-failed counts, group/fold counts, out-of-fold log10 MAE/RMSE for both ridge and training-fold mean, and failure reasons. No per-row ground truths, chemical identities, source names, individual predictions, secret material rosters or MACE weights in Actions artifacts. Exactly reproducible via the pinned Git checkout and source code.

**Interpretation:** this evaluates original OBELiX's public curated numeric *source metadata* and one simple composition model. It **does not** evaluate MACE ionic conductivity, MD diffusion, physical bulk-vs-total apples-to-apples temperature-normalized quantities, independent new materials, official public TEST, private blind generalization, or independently authenticated experiment truth. It **must never** be combined with 0145's 39 successful energy+force calculations as if those represented 39 experimentally scored conductivities. It establishes a scientifically transparent, larger **PUBLIC_DIAGNOSTIC_GROUPED_OOF** evaluation with experiment provenance still unqualified.
