# Priority 5 — 선분 반영 격자 및 주기 이미지 검증

## 한계와 기존 모델

과학 판정 `SCIENTIFIC NO-GO / ABSTAIN`. Priority 4에서 비교한 실제 charge-scaled evaluator는 이미 cutoff=8 Å의 모든 주기 이미지를 합산하고, 7–8 Å quintic C² taper와 정확한 product-rule 힘을 사용했다. 따라서 무 cutoff MIC 모드의 kink 또는 이번 2회 제한 최적화 실패를 이전 결정 계산의 원인으로 단정할 수 없다. 특이점 및 근접 host core의 모델 정확성은 검증되지 않았다.

새 `segment_percolation`은 각 26-neighbor edge를 최대 0.2 Å 간격으로 표본화한 최대 에너지로 연결·winding rank를 계산한다. 유한 표본의 최대값은 연속 edge의 참 최대를 보장하지 않는다. 원본 26-neighbor 기본 구현과 이전 감사 결과는 유지한다. 각 3D witness는 0.025 Å로 별도 검사했으나 완전한 연속 검증은 아니다.

재검사 차이는 독립 witness 재표본 최대 − 그래프 threshold다. 음수는 검증 표본이 그래프의 다른 표본 위치를 반드시 포함하지 않기 때문에 가능하다. 세 구조 모두 원점·격자에 따른 차이가 남고 전역 연속 수렴은 확인되지 않았다. Li2S n16 원점0의 감사 JSON을 독립 재실행한 결과 시간 필드를 제외하고 정확히 같았다.

| lialo2 | 0.4440 / 0.4440 | True / 0.0490 | 0.8999 → 0.8999 |

string은 정해진 하나의 winding cycle에서 projected force ≤0.05 eV/Å인 경우만 `converged=True`로 표기한다. 세 경로 연결의 보존, 전역 최소, MD 예측 또는 정량적 물질 인증은 입증하지 않는다. 단일 witness barrier는 다른 cycle이 결정하는 3D graph threshold와 같을 필요가 없다. clearance graph도 유한 표본과 검증되지 않은 입력 이온 반경을 쓴다.

세 보존 CIF별 3점 및 2×2×2 supercell 비교에서 원본과 supercell 에너지 최대 차이는 2.84e-14 / 7.66e-15 / 7.11e-14 eV, 힘 최대 성분 차이는 1.08e-13 / 2.27e-13 / 2.38e-13 eV/Å였다. 세 점의 유한차분 힘 최대 성분 오차는 각각 7.58e-8 / 2.49e-7 / 2.70e-8 eV/Å다. 별도 cutoff 및 MIC 경계 단위 테스트는 통과했으나 이는 제한된 점에 대한 수치 검증이다.

## 72구조 후향적 거리 비교

원소 집합은 기존 `ANIONS` registry이며 서로 다른 사이트의 MIC 거리만 포함하고 주기적 자기 이미지는 제외한다. 음이온–음이온은 P–O 및 B–O 같은 양이온–음이온 결합과 분리되지만, 이온성이나 충돌을 자동 증명하지 않는다. 완료·폭발 혼합 4구조는 이 기존 집계에서 제외됐다.

|---|---|---|---|---|

이 차이는 화학종·체적·선택 조건이 얽힌 후향적 관찰이다. 폭발의 원인이나 실제 수송 특성에 대한 인과적 결론은 보류한다. 72개 행과 출처 해시는 `priority5_steric_v1.json`에 기록했다.

## 재현

각 CIF별 `scripts/diagnostics/priority5_graph.py --cif <repo-relative-CIF> --n <16|20|24> --origin <0|0.5> --edge-spacing .2 --output <new-file>`로 실행한다. 다른 driver는 `priority5_periodic.py`, `priority5_string.py`, `priority5_clearance.py`, `priority5_steric.py`이며 모두 기존 출력을 덮어쓰지 않는다. 커밋 이전 실행의 input/code hash와 실행 설정은 각 JSON에 저장된다.
